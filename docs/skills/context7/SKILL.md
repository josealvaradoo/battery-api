# Context7 Skill

Context7 is a MCP tool for fetching any package, framework or language documentation using the terminal by npm.

## When to use

Use this skill when you have to use a tool, package, framework or language and you need more documentation.

## How to use

When asked to use any tool, package, framework or language, you have to use the context7 MCP to fetch the documentation.

1. Detect what's the package, framework, tool or language to use.
2. Check if Context7 MCP is available.
3. Run the Context7 MCP tool for fetching the documentation, or request to the user provide the tool.

### Examples

```txt
Prompt example: "Act as an agent and fetch the playwright documentation using the Context7 MCP tool".
```
